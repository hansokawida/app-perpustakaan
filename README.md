Menurut pemahaman saya, **Model** bertugas mengelola data dan berhubungan dengan database, **View** bertugas menampilkan data kepada pengguna, sedangkan **Controller** menjadi penghubung yang mengatur proses antara Model dan View. Dengan pembagian ini, setiap bagian memiliki tugas yang jelas sehingga aplikasi lebih mudah dikembangkan dan dipelihara.
